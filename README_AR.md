# AB Wallet — النسخة التجريبية الأولى

تطبيق Android تجريبي لمحفظة رقمية بواجهة عربية وداكنة.

## الموجود في النسخة
- شاشة دخول باستخدام Google (تحتاج إعداد OAuth قبل أن تعمل فعليًا).
- وضع استعراض لفتح الواجهة دون تسجيل حساب.
- لوحة رصيد تجريبي بالجنيه المصري.
- إيداع وسحب وتحويل افتراضي داخل التطبيق فقط.
- رسم بياني لحركة الرصيد التجريبي.
- سجل عمليات تجريبية.
- واجهة لطرق الدفع (بطاقة بنكية، محفظة هاتف، تحويل بنكي) وهي غير مفعّلة.
- أيقونة AB Wallet مدمجة في التطبيق.

## تنبيه مهم
هذا نموذج واجهة وتجربة فقط. لا يستقبل أموالًا حقيقية، ولا يحتفظ بأرصدة حقيقية، ولا ينفّذ تحويلات أو مدفوعات. لا تدخل بيانات بطاقات أو حسابات بنكية حقيقية فيه. تشغيل منتج مالي حقيقي يحتاج كيانًا مرخصًا أو شريك دفع مرخصًا، وخادمًا آمنًا للتحقق من الهوية والمعاملات، ومراجعة قانونية ومتطلبات البنك المركزي المصري.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (يكون `settings.gradle.kts` و`app/` و`.github/` في الجذر مباشرة، وليس داخل مجلد إضافي).
2. افتح تبويب Actions.
3. اختر `Build AB Wallet APK` ثم `Run workflow`.
4. بعد نجاح البناء افتح نتيجة التشغيل، وانزل إلى Artifacts، وحمّل `ab-wallet-apk`.
5. فك ضغط ملف ZIP الناتج، ثم ثبّت ملف APK على هاتف Android.

## إعداد تسجيل الدخول بحساب Google
زر Google موجود، لكنه لن يعمل قبل إضافة OAuth Client ID:
1. أنشئ مشروعًا في Google Cloud Console.
2. جهّز OAuth Client لتطبيق Android باسم الحزمة `com.abwallet.app` وبصمة SHA-1 لشهادة التوقيع التي ستستخدمها.
3. أنشئ أيضًا OAuth Client من نوع Web application.
4. استبدل القيمة التجريبية في `app/src/main/res/values/strings.xml` بقيمة Web Client ID الفعلية، مع الإبقاء على اسم المورد `default_web_client_id`.
5. أعد البناء. عند النشر، استخدم بصمة شهادة Play App Signing التي توفرها Google Play، وليس بصمة debug.

ملاحظة تقنية: الحصول على حساب Google داخل التطبيق ليس وحده نظام مصادقة ماليًا آمنًا. قبل أي استخدام حقيقي يجب إرسال رمز الهوية إلى خادم موثوق والتحقق منه على الخادم.
